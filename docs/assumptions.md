# Допущения

Сюда записывается всё, чего нет в методичке явно, но что понадобилось для симуляции: допустимые диапазоны, время процессов, смоделированные последствия ошибок, выбранное толкование неоднозначных мест.

Автор проверяет этот список и исправляет то, что не соответствует реальной практике кафедры.

Формат записи:

```
## Работа №N, опыт N.N, шаг K — краткое название
- Что принято: …
- Почему: …
- Источник/основание: методичка с. …, общая лабораторная практика, …
```
