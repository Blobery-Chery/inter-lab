# Виртуальная лаборатория · Виртуалды зертхана · Virtual Laboratory

**Химия функциональных производных органических молекул** — виртуальный практикум для студентов 3 курса специальности «Химия»: инструктаж по технике безопасности, допуск к работам, выполнение работ по методическим указаниям и протокол с оценкой. Русский, казахский и английский языки; компьютер и телефон.

**Органикалық молекулалардың функционалдық туындыларының химиясы** — «Химия» мамандығының 3-курс студенттеріне арналған виртуалды практикум.

**Chemistry of Functional Derivatives of Organic Molecules** — a virtual laboratory course for third-year chemistry students.
