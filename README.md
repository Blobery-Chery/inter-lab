# Виртуальная лаборатория

Лабораторные работы дисциплины в браузере: допуск к работе, реальный ход работы с последствиями ошибок, подсказки и протокол. Русский, казахский и английский языки. Работает на компьютере и телефоне, после первой загрузки — без интернета.

## Как открыть

Сайт публикуется через GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Адрес будет вида `https://<имя>.github.io/<репозиторий>/`.

Ссылка для зачёта (без подсказок): добавьте в конец адреса `?mode=exam`.

Панель преподавателя: `…/teacher/` (вход по логину и паролю). Чтобы ответы студентов приходили преподавателю, один раз настройте сервер по инструкции `backend/README.md` и вставьте его адрес в `config.js`. Без этого сайт работает в локальном режиме.

Дисциплина: «Химия функциональных производных органических молекул», 3 курс. Вводное занятие по технике безопасности и оборудованию, работы № 6–15.

## Для разработки

```
python3 -m http.server 8000     # открыть http://localhost:8000
node --test tests/              # проверки
```

Устройство проекта и правила — в `CLAUDE.md` и `docs/SPEC.md`.
